# AI 협업 기록

사용 도구: Codex, Claude

## AI가 맡은 일

- 낯선 개념을 설명하고 구현 초안을 제시
- 오류 원인 후보와 반례를 넓게 제안
- 반복 실험과 결과 요약을 자동화
- 공개 문서 구조와 표현을 정리

## 사람이 맡은 일

- 해결할 문제와 평가 기준 선택
- 원본 데이터와 실행 결과 대조
- holdout·교차검증·누수 방지 규칙 결정
- 유리하지만 재현되지 않은 주장 철회
- 실제 사용 여부와 한계 공개

AI가 생성한 설명은 증거가 아닙니다. 최종 주장은 원본, 실행 결과, 재현 코드 중 하나 이상에 연결하고, 연결되지 않는 문장은 삭제했습니다.
