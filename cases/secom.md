# SECOM 불량 탐지 — 결과보다 검증 설계

## 문제

불량률이 6.64%인 불균형 데이터에서 Accuracy 93.3%는 유용한 모델을 뜻하지 않았습니다. 기본 임계값에서 모든 샘플을 정상으로 분류해 holdout 불량 21건을 모두 놓쳤습니다.

## 재검증 설계

1. 전체 데이터는 80/20 층화 분할하고 holdout은 마지막까지 사용하지 않았습니다.
2. 결측률·상수 열 제거와 중앙값 대치는 각 fold의 학습 부분으로만 fit했습니다.
3. 특성 선택 실험의 중요도 순위도 fold 내부에서만 fit했습니다.
4. operating threshold는 학습 5-fold OOF의 불량 점수만으로 정했습니다.
5. holdout에는 결정된 파이프라인과 임계값을 한 번 적용했습니다.
6. 불량/정상을 각각 재표집하는 2,000회 bootstrap으로 불확실성을 확인했습니다.

## 결과

| 항목 | 기본 0.5 | OOF 임계값 0.0717 |
|---|---:|---:|
| TP / FN | 0 / 21 | 19 / 2 |
| FP / TN | 0 / 293 | 117 / 176 |
| Recall | 0.0% | 90.5% |
| Precision | 0.0% | 14.0% |
| 재검사율 | 0.0% | 43.3% |
| PR-AUC | 0.238 | 0.238 |

임계값은 분류 지점을 바꿀 뿐 점수의 순위 성능인 PR-AUC를 개선하지 않습니다. 이 operating point는 미탐 감소와 재검사 증가를 보여주는 예시입니다.

## 반증된 주장

기존 분석의 “상위 80개 센서가 더 낫다”는 결과는 전체 학습 데이터로 중요도 순위를 정한 뒤 CV를 수행해 선택 편향이 개입할 수 있었습니다. 순위 계산을 fold 안으로 옮긴 3회 반복 5-fold CV 결과는 다음과 같습니다.

| 특성 수 | 평균 PR-AUC | 표준편차 |
|---:|---:|---:|
| 20 | 0.131 | 0.010 |
| 40 | 0.141 | 0.026 |
| 80 | 0.137 | 0.010 |
| 전체 | 0.168 | 0.026 |

따라서 상위 80개 우월 주장을 철회하고, 최종 기준선은 학습 fold에서 유효한 전체 450개 특성을 사용했습니다.
